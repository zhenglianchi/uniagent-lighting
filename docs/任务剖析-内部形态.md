## 1. 任务本体：humanevalfix-Python-111

**题目**：修复 `/testbed/solution.py` 里的 `histogram(test)`——输入空格分隔的小写
字母串，返回出现次数最多的字母及其次数；并列时返回全部；空串返回 `{}`。

**buggy 实现**（`work/data/humanevalfix_train161.jsonl` 第 98 条
`extra_info.tools_kwargs.env.files.solution.py`）：

```python
def histogram(test):
    ...
    dict1={}
    list1=test.split(" ")
    t=1
    for i in list1:
        if(list1.count(i)>t) and i!='':
            t=list1.count(i)
    if t>0:
        for i in list1:
            if(list1.count(i)==t):
                dict1[i]=t
    return dict1
```

**bug 定位**：`histogram('')` → `''.split(" ")` = `['']`，第二轮循环把空串也
计入 → 返回 `{'': 1}`，而期望是 `{}`（hidden test 第 7 条断言）。修复方向：
结果收集时排除空串 / 空输入直接返回 `{}`。

**hidden test**（`reward_model.ground_truth.hidden_files.test_solution.py`）：
`FAIL_TO_PASS = ["test_solution.py::test_all"]`，8 条断言覆盖空串、单字母、
全并列等 case——训练和 agent 阶段**不注入**，只在 reward 阶段写入沙箱。
