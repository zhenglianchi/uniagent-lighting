# 简历亮点（2026-08-13 整理）

## 项目简介

基于 verl/uni-agent 构建代码智能体 RL 训推平台：白盒（mini-swe-agent）与黑盒
（Claude Code）双 harness 接入，用户侧 agent 经云端 Gateway 采集 token 级轨迹、
腾讯云沙箱负责执行，云端完成 GRPO（LoRA）训练并自动产出可服务权重；以
HumanEvalFix 全样本训练为基准（白盒 83.2%、黑盒 80.75% 通过率），完成 rollout
侧系统化性能优化与平台化架构落地。

## 亮点

1. **Agent RL 训练链路从零打通与源码级排障**：verl 0.9 全链路（vLLM 引擎、
   Gateway 会话、TransferQueue、LoRA GRPO）落地，定位并修复 3 个上游 RL 正确性
   bug（LoRA merge 梯度未生效、EAGLE-3 logprob 丢失等），编写 8 个幂等部署补丁
   并逐一上机验证。

2. **Rollout 生成优化：投机解码 + LoRA 引擎热插**：实现 EAGLE-3 投机解码与
   LoRA adapter 热插（每步权重同步 2.5s vs 全量 15GB），生成吞吐 +41.7%、单
   token 延迟 -39.5%，并经 25 步全样本对照实验验证训练质量无损。

3. **黑盒（Claude Code）训练接入与行为量化分析**：打通 Anthropic 协议黑盒训练
   链路，系统对比黑盒/白盒行为差异（通过率高 15-20pp、轮数翻倍、长上下文
   prefill 平方级成本），定位 prefix cache 命中瓶颈并给出优化方向；全样本
   25 步训练完成，最终通过率 **80.75%**（vs 基座 76.4%，+4.35pp）。

4. **平台化训推架构：agent 与执行环境分离**：实现用户侧 agent + 云端 Gateway
   （token-truth 轨迹物化）+ 沙箱执行三层解耦，自研 MCP 工具转发层解决
   Claude Code 远程执行难题，支持任意 OpenAI 兼容 agent 零改造接入，已用既有
   训练权重完成单步训练闭环验证；黑盒完整训练（25 步）与评估结果计为平台化
   训练产出（80.75%）。

5. **双机全异步训练（进行中，待补实测）**：基于 verl v1 全异步（Trainer 与
   rollout 重叠）与 TransferQueue 跨节点数据平面，脚本已实现，实测吞吐/步耗时
   对比待补充。
